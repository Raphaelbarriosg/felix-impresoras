# Félix Impresoras - Premium Landing Page

Landing page profesional para Félix Impresoras, negocio especializado en venta, reparación y mantenimiento de impresoras, así como venta y recarga de cartuchos y tóners.

## 🎨 Diseño y Estética
- **Estilo:** Dark Luxury Corporate
- **Color Principal:** Electric Blue (`#3B82F6`)
- **Tipografía:** Plus Jakarta Sans (Títulos) e Inter (Cuerpos de texto)

## 📁 Estructura del Proyecto
```
/
├── index.html        # Estructura principal
├── styles.css        # Estilos, variables, glassmorphism y animaciones
├── script.js         # Interacciones (flip cards, scroll, partículas)
└── images/           # Assets visuales
    ├── logo.png
    ├── hero_visual.png
    └── service_1.png a service_4.png
```

## ✨ Características Principales
- **Totalmente Responsive:** Adaptable a Desktop, Tablet y Mobile.
- **Glassmorphism:** Tarjetas con efecto de cristal esmerilado.
- **Animaciones:** Sistema de partículas de fondo, hover states avanzados, contadores animados y scroll reveal.
- **Flip Cards:** Tarjetas de servicios interactivas (flip 3D).

## 🚀 Despliegue
Este proyecto está compuesto únicamente por HTML, CSS y JS vanilla (estáticos), por lo que es ideal para ser desplegado de manera gratuita y rápida en plataformas como:
- [Vercel](https://vercel.com/)
- [GitHub Pages](https://pages.github.com/)
- [Netlify](https://www.netlify.com/)

Para desplegar en Vercel:
1. Sube este repositorio a tu cuenta de GitHub.
2. Inicia sesión en Vercel con tu cuenta de GitHub.
3. Importa el repositorio.
4. Haz clic en "Deploy" (no requiere configuraciones adicionales de build).
